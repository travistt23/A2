# 🏦 Smart Finance Assistant

## 📌 Overview
This project is a Python-based AI-powered finance assistant that helps users analyse spending, track transactions, and receive financial advice.

It uses:
- Pandas for data analysis
- Hands-on-ai for chat, RAG, and tools
- Gradio for UI

---

## 🚀 Features

### 📊 Transaction Analysis
- Upload CSV files
- Clean and process spending data
- Group spending by category

### 🤖 AI Chat Assistant
- Financial advice chatbot
- Responds to spending behaviour questions

### 🔍 RAG System
- Answers finance questions using contextual data

### 🛠️ Savings Tool
- Calculates time needed to reach savings goals

### 🌐 Web Interface
- Built using Gradio
- Simple user-friendly dashboard

---

## ▶️ How to Run

1. Open `smart_finance_assistant.ipynb`
2. Run all cells from top to bottom
3. Upload sample CSV or use built-in dataset
4. Launch Gradio UI at the end

---

## 📊 Example

**Input:**
“I spend too much on coffee”

**Output:**
AI suggests budgeting strategies and monthly limits.
